# SEO Guide

## Что уже реализовано в теме

- ЧПУ для услуг: `/services/slug/`
- ЧПУ для проектов: `/portfolio/slug/`
- fallback `title` и `meta description`
- canonical
- Open Graph
- Breadcrumbs
- JSON-LD: `Organization`, `LocalBusiness`, `Service`, `BreadcrumbList`, `Article`
- семантическая верстка иерархией `H1-H3`

## Почему выбран `LocalBusiness`, а не `Electrician`

Компания оказывает не только электромонтажные работы, но и услуги по пожарной сигнализации, СОУЭ, СКС, СКУД, видеонаблюдению, охранным системам и ПНР. Тип `Electrician` был бы слишком узким. Поэтому в теме используется связка `Organization + LocalBusiness`.

## Совместимость с SEO-плагинами

- Если установлен `Rank Math` или `Yoast SEO`, тема не дублирует fallback мета-теги.
- Можно оставить schema темы выключенной по умолчанию при активном SEO-плагине.

## Рекомендации по настройке

### Постоянные ссылки

Используйте структуру:

```text
/%postname%/
```

### Sitemap

- Подойдет sitemap от Rank Math, Yoast или стандартный sitemap WordPress.
- Убедитесь, что в sitemap входят:
  - страницы
  - записи
  - `service`
  - `portfolio`

### Robots.txt

Базовая рекомендация:

```text
User-agent: *
Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php

Sitemap: https://example.com/sitemap_index.xml
```

### Alt у изображений

- В каждой карточке проекта и услуге задавайте осмысленный alt
- Не используйте спам-формулировки и перечисления ключей

## Технические рекомендации для PageSpeed 85+

1. Используйте WebP/AVIF для визуала.
2. Настройте кэш страниц и кэш браузера.
3. Подключите SMTP вместо стандартной почты PHP.
4. Не ставьте лишние page-builder addons.
5. Минимизируйте количество сторонних скриптов аналитики.
6. Используйте CDN, если проект ориентирован на трафик из нескольких регионов.
7. Оптимизируйте шрифты и не подключайте лишние веса.
8. Включите lazy loading для изображений ниже первого экрана.

## Коммерческое SEO

- Для каждой услуги создайте отдельную страницу с конкретным интентом
- Не дублируйте тексты между услугами
- Для проектов используйте реальные типы объектов, города, сроки и состав работ
- Ведите блог по околотематическим вопросам: эксплуатация, приемка, нормативы, безопасность
