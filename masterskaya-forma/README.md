# Мастерская «Форма» — демо-сайт мебельной мастерской

Статический многостраничный сайт мастерской кухонь на заказ. Главная особенность —
конфигуратор: посетитель выбирает планировку, длину стены, фасады, столешницу,
фурнитуру и опции, а параметрический чертёж и цена пересчитываются мгновенно.
Состояние конфигурации сохраняется в адресе страницы, поэтому ссылку на расчёт
можно переслать.

Демонстрационный проект: компания, адрес, телефон и цены вымышлены. Пометка об этом
есть в подвале и на странице контактов, флаг `site.demo` в `src/data/site.mjs`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run build` | собирает `dist/`: страницы, CSS, карта сайта, `.htaccess` |
| `npm run serve` | локальный сервер на `http://127.0.0.1:4173/` |
| `npm run check` | приёмка в браузере: переполнение, консоль, ссылки, конфигуратор, фильтр, формы |
| `npm run fonts` | скачивает и самохостит шрифты (Golos Text, IBM Plex Mono) |
| `node scripts/shots.mjs` | скриншоты страниц через Chrome DevTools Protocol |
| `node scripts/og.mjs` | пересобирает OG-картинку из настоящего чертежа |

Внешних зависимостей нет: сборка, сервер и проверки написаны на голом Node.

## Структура

```
build.mjs                  генератор dist/
public/                    копируется в корень: favicon, robots.txt, send.php, .htaccess папки data
src/
  data/                    контент: site.mjs (реквизиты, обещания), catalog.mjs (проекты), faq.mjs
  pages/                   страницы: home, configurator, projects, project, materials, production,
                           contacts, privacy, extra (спасибо и 404), registry (список для сборки)
  render/                  общее: layout.mjs (шапка, подвал, окно заявки), blocks.mjs, icons.mjs
  assets/
    css/                   fonts.css (генерируется), base, layout, components, pages
    fonts/                 woff2, кириллица и латиница
    js/
      app.js               меню, появление блоков, cookie, фильтр каталога
      tool.js              логика конфигуратора
      forms.js             отправка заявок и запасной путь через Telegram
      site-data.js         генерируется сборкой для браузера
      shared/              изоморфный код: pricing.js, drawing.js, toolview.js, format.js
```

## Как это устроено

**Один код на сервере и в браузере.** `shared/drawing.js` и `shared/pricing.js` не
используют DOM, поэтому сборка рисует начальное состояние конфигуратора, а браузер
перерисовывает его при изменении параметров. Расчёт в первом экране и в полном
конфигураторе физически не могут разойтись — это одна функция.

**Чертёж — параметрический SVG.** Система координат в сантиметрах: одна единица
viewBox равна одному сантиметру. Штрихи рисуются с `vector-effect="non-scaling-stroke"`,
поэтому остаются волосяными при любом размере. Подписи размеров вынесены в HTML
поверх SVG: иначе на телефоне они становятся нечитаемыми.

**Цена считается по открытой формуле,** которая описана на странице «Материалы»:
погонные метры × (корпус + фасад + столешница + фурнитура) + опции + 8 % на доставку
и сборку, вилка ±7 %. Проекты в каталоге считаются той же функцией.

**Заявки.** `public/send.php` проверяет данные на сервере, отсекает спам скрытым полем
и ограничением частоты, пишет заявку в `data/leads.jsonl` и пытается отправить письмо.
Секретов в клиентском JavaScript нет. Если PHP недоступен, `forms.js` не теряет заявку:
копирует текст в буфер и открывает чат Telegram.

## Что проверено

`npm run check` — 50 проверок в настоящем браузере: десять страниц на 360, 768 и 1440 px
без горизонтального переполнения, ноль ошибок в консоли и битых запросов, все внутренние
ссылки и якоря, работа конфигуратора (планировка, ползунок, фасад, палитра, адрес,
перерисовка чертежа), окно заявки (помещается в экран целиком, без полос прокрутки,
подставляет состав заказа), фильтр каталога, cookie-уведомление и мобильное меню.

Вес главной страницы — около 187 КБ вместе со шрифтами и всем JavaScript.

## Что уже ломалось и как закрыто

- **Окно заявки распирало полосами прокрутки.** В описание заявки попадала полная ссылка
  на конфигурацию — длинная строка без пробелов не переносилась и растягивала окно.
  Теперь в окне показывается состав заказа человеческим языком, а ссылка уходит на сервер
  отдельным полем; для длинных строк добавлен `overflow-wrap: anywhere`. Проверка
  `npm run check` следит за шириной, высотой и отсутствием прокрутки в окне.
- **Переполнение на телефоне.** Авто-колонки сеток растягивались по самому длинному слову —
  все сетки переведены на `minmax(0, 1fr)`.
- **Вопросы в FAQ оставались невидимыми.** Правило скрытия перебивало правило появления
  по специфичности; список обёрнут в `:where()`, чтобы специфичность обнулилась.
- **Цвет фасада сбрасывался** на первый из палитры, если в адресе не было параметра `color`.
