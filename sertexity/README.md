# Sertexity — промо-сайт платформы AI-арбитража

Статический сайт на девять страниц: движок арбитража, покрытие бирж, калькулятор
доходности, вопросы и контакты. Собран генератором страниц на голом Node —
внешних зависимостей и сборщиков нет.

Живой адрес: **https://masterskaya-forma.online/**

## Что внутри

- **Глобус арбитража на Canvas 2D.** Двенадцать площадок, маршруты между ними и
  бегущие по маршрутам «пакеты». Ортографическая проекция и вращение считаются
  вручную, без Three.js и WebGL-зависимостей. Уважает `prefers-reduced-motion`.
- **Калькулятор доходности.** Депозит, профиль риска, срок и реинвест: пересчёт
  без перезагрузки, кривая роста на Canvas и разбивка «доход — доля платформы — на руки».
- **Бегущая строка котировок** с обновлением и **живой лог сделок** в стиле терминала,
  включая отклонённые сигналы и раскрученные позиции.
- **Таблицы маршрутов:** биржи с комиссиями и задержками, пары с наблюдаемым спредом.
- **Форма заявки** с серверной проверкой: ловушка для ботов, ограничение частоты,
  запись в файл и возврат на страницу со статусом.

## Команды

| Команда | Что делает |
| --- | --- |
| `node build.mjs` | собирает `dist/`: страницы, CSS, карта сайта, `.htaccess` |
| `node scripts/serve.mjs` | локальный сервер на `http://127.0.0.1:4174/` |
| `node scripts/check.mjs` | 39 проверок в браузере: ширины, консоль, ссылки, глобус, калькулятор, форма |
| `node scripts/og.mjs` | пересобирает картинку для соцсетей из настоящей вёрстки |

## Структура

```
build.mjs                  генератор dist/
public/                    favicon, картинка для соцсетей, send.php, .htaccess
src/
  data/site.mjs            контент: биржи, пары, тарифы, вопросы
  render/layout.mjs        шапка, подвал, мета-теги, микроразметка
  pages/                   страницы: home, how-it-works, markets, calculator, faq, contacts, privacy, extra
  assets/
    css/                   переменные, база, типографика, сетка, компоненты, секции
    js/                    app.js (общий сценарий), globe.js, calculator-page.js
    fonts/                 Inter и JetBrains Mono, самохостятся
```

## Что проверено

`node scripts/check.mjs` — 39 проверок: девять страниц на 360, 768 и 1440 px без
горизонтального переполнения, ноль ошибок в консоли и битых запросов, все внутренние
адреса отвечают 200, глобус рисуется, тикер и лог собираются скриптом, калькулятор
пересчитывает итог и строит график, мобильное меню открывается, форма имеет
обязательные поля, ловушку и согласие. Вес главной со шрифтами — 143 КБ.

## Демонстрационный характер

Sertexity — образец для портфолио. Платформа, цифры доходности и упоминание SEC CIK
взяты из исходного макета Figma; сайт не является инвестиционным предложением,
а расчёт в калькуляторе — арифметика заявленного диапазона, а не прогноз.
