# Портфолио: сайты под ключ

Три проекта в одном репозитории. Первый — сайт-портфолио, второй — демонстрационный сайт
мастерской мебели с конфигуратором, третий — тема WordPress для подрядчика инженерных
систем с калькулятором стоимости. Оба демо-проекта выступают в портфолио кейсами:
их можно открыть, потрогать механики и увидеть, как такой сайт устроен изнутри.

| Проект | Что это | Живой адрес |
| --- | --- | --- |
| [`portfolio-site/`](portfolio-site/) | Сайт-портфолио: услуги, работы с разбором, процесс, контакты | https://rootlost.online/ |
| [`masterskaya-forma/`](masterskaya-forma/) | Демо-сайт мастерской кухонь с конфигуратором | https://masterskaya-forma.ru/ |
| [`kitstroy-moscow/`](kitstroy-moscow/) | Тема WordPress для подрядчика инженерных систем и калькулятором | https://rootlost.ru/ |

## Чем интересен сайт инженерного подрядчика

Центр сайта — калькулятор стоимости с открытой формулой: тип объекта, площадь, высота
потолков, состав систем и удалённость от МКАД. Рядом — однолинейная схема питания,
которая подсвечивает группы, и заявка-квиз из трёх шагов со сводкой по объекту.

- **Формула открыта.** Ставки по типам объектов и коэффициенты систем описаны на сайте,
  а не спрятаны за «менеджер посчитает». Смета в калькуляторе и в заявке считается
  одной и той же функцией.
- **Схема питания — не картинка.** Однолинейная схема построена в SVG, группы
  подсвечиваются наведением и реагируют на состав систем в калькуляторе.
- **Объекты со спецификацией.** У каждого объекта видны площадь, расчётная мощность,
  число линий и ориентир сметы: по каталогу понятно, работает ли подрядчик с вашим масштабом.
- **Своя тема без конструкторов.** Сборка на `build.mjs`: SCSS и скрипты кладутся
  в `assets/dist`. Формы работают на нативном `admin-post.php` с nonce и honeypot.

## Чем интересен демо-сайт мастерской

Центр сайта — не каталог, а конфигуратор. Посетитель выбирает планировку, длину стены, фасад,
столешницу, фурнитуру и опции, а параметрический чертёж и цена пересчитываются мгновенно.

- **Чертёж рисуется кодом.** Фасад кухни, план расстановки, секции, ящики, вытяжка с трубой
  и размерные линии строятся параметрически в SVG. Одна единица системы координат равна
  одному сантиметру, поэтому подписи размеров настоящие.
- **Один код на сервере и в браузере.** Модули `drawing.js` и `pricing.js` не используют DOM:
  сборка рисует начальное состояние, браузер перерисовывает его при изменении параметров.
  Расчёт в первом экране и в полном конфигураторе не могут разойтись — это одна функция.
- **Состояние конфигурации живёт в адресе страницы.** Ссылку на расчёт можно переслать,
  у всех откроется одна и та же кухня с той же ценой.
- **Заявки работают по-настоящему.** Обработчик на PHP проверяет данные на сервере, отсекает
  спам скрытым полем и ограничением частоты, пишет заявку в файл и отправляет письмо.
  Если сервер недоступен, заявка не теряется: текст копируется в буфер и открывается Telegram.
- **Пятнадцать страниц собираются генератором** из данных, а не копированием вёрстки.
  Внешних библиотек на клиенте нет, вес главной страницы со шрифтами и всем JavaScript — 187 КБ.

## Чем интересен сайт-портфолио

- Работы не открываются в модальном окне: у каждой свой адрес `case.html?work=<id>` с обложкой,
  разбором решений, крупными экранами и формой заявки.
- В рамке браузера страница проекта **прокручивается сама** — видно то, чего не показывает
  статичный скриншот. При `prefers-reduced-motion` прокрутка отключается.
- Весь интерфейс проверяется скриптом в настоящем браузере через Chrome DevTools Protocol.

## Как запускать

Каждый проект независим, зависимости есть только у портфолио.

```bash
# Сайт-портфолио
cd portfolio-site
npm ci
npm run build        # типы и сборка в dist/
npm run dev          # локальная разработка
npm run check:responsive   # приёмка в браузере на 360, 768 и 1440

# Демо-сайт мастерской (зависимостей нет вовсе)
cd masterskaya-forma
node build.mjs       # сборка в dist/
node scripts/serve.mjs     # локальный просмотр
node scripts/check.mjs     # 50 проверок в браузере

# Тема WordPress для инженерного подрядчика
cd kitstroy-moscow
node build.mjs       # SCSS в CSS и скрипты в assets/dist
```

Для проверок нужен Chrome или Edge. Путь можно задать переменной `CHROME_PATH`.

## Публикация

Выгрузка идёт по FTP и запускается вручную: **Actions → Публикация → Run workflow**.
Цель `kitstroy` выгружает только тему WordPress в `wp-content/themes/kitstroy-moscow`.
Нужны секреты репозитория `FTP_HOST`, `FTP_USER`, `FTP_PASS` — в коде и в файлах доступы
не хранятся, скрипты читают их из переменных окружения.

```bash
gh secret set FTP_HOST --body "31.31.196.221"
gh secret set FTP_USER --body "…"
gh secret set FTP_PASS --body "…"
```

## Что проверяется автоматически

При каждом push и pull request workflow «Проверки» собирает все три проекта и запускает
браузерные тесты: страницы портфолио и пятнадцать страниц демо-сайта на трёх ширинах,
горизонтальное переполнение, ошибки в консоли, битые запросы, ссылки и якоря, работу
конфигуратора, фильтра, форм и cookie-уведомления. Для темы проверяются сборка стилей,
кодировка исходников и совпадение `assets/dist` с исходниками. Отчёт и скриншоты
остаются артефактом сборки.
