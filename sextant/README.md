# СЕКСТАНТ — сайт часовой мануфактуры

Демонстрационный сайт вымышленной часовой мануфактуры из Санкт-Петербурга.
Пятый кейс портфолио и самая крупная работа в репозитории: трёхмерный механизм
в браузере, разборка калибра на узлы и конфигуратор с живой моделью.

Живой адрес: **https://rootlost.online/sextant/**

## Что внутри

- **Одиннадцать страниц** — главная, коллекция, калибр, конфигуратор, ателье, сервис,
  галерея, контакты, обработка данных, спасибо и 404. Собираются генератором на голом Node:
  ни сборщика, ни зависимостей, кроме three.js.
- **Три сцены на WebGL** — механизм в первом экране, разборка на узлы на странице калибра
  и часы целиком в конфигураторе.
- **Пятнадцать изображений** — рендеры той же трёхмерной модели, снятые в headless-браузере.
  Стоковых фотографий на сайте нет.
- **Процедурная отделка** — женевские полосы, зернение, круговое шлифование, солнечные лучи
  и кожа: карты высот, из которых собелём считаются карты нормалей.

## Запуск

```bash
node build.mjs             # сборка в dist/
node scripts/serve.mjs 4176   # локальный просмотр
node scripts/check.mjs     # 50 проверок в браузере, включая 3D-сцены
node scripts/render.mjs    # пересъёмка изображений с трёхмерной модели
node scripts/fetch-fonts.mjs  # обновление самохостинговых шрифтов
```

Публикация сайта идёт в подпапку, поэтому адреса страниц собираются с префиксом:

```bash
SEXTANT_BASE=/sextant node build.mjs
```

Для проверок нужен Chrome или Edge — путь можно задать переменной `CHROME_PATH`.
Скрипт рендера запускает браузер с программным WebGL (`--enable-unsafe-swiftshader`),
поэтому видеокарта не требуется.

## Структура

```
build.mjs            сборка: ассеты, CSS в один файл, страницы, sitemap, robots, .htaccess
public/              favicon, обработчик формы, готовые файлы поверх сборки
scripts/             сервер для просмотра, проверки в браузере, рендер изображений
src/data/content.mjs все тексты, модели, цены и характеристики
src/render/layout.mjs  оболочка страниц: head, шапка, подвал, микроразметка
src/pages/           страницы сайта
src/assets/css/      стили: токены, каркас, элементы, блоки
src/assets/js/gl/    трёхмерная часть: калибр, часы, материалы, текстуры, сцена
src/assets/js/       общий сценарий, появление блоков, сценарии страниц
src/assets/img/      изображения — рендеры модели
src/vendor/          three.js 0.185, минифицированные сборки
```

## Демонстрационный характер

Бренд, модели, цены, адрес и контакты придуманы. Честная пометка об этом есть в подвале
сайта и в разделе «Обработка данных». Форма заявки проверяет данные на сервере
(`public/send.php`), но писем не отправляет: заявка складывается в файл рядом с сайтом.
