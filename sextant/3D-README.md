# Просмотр 3D-часов

## Windows
1. Распакуйте архив полностью.
2. Если Node.js уже установлен, дважды щёлкните START-3D.bat в папке sextant. Иначе сначала установите Node.js LTS.
3. Откроется http://127.0.0.1:4176/configurator/ . Если страница открылась раньше сервера, обновите её.
4. Оставьте окно консоли открытым на время просмотра. Для остановки нажмите Ctrl+C.

## Ручной запуск
Из папки sextant:

```bash
node build.mjs
node scripts/serve.mjs 4176
```

Откройте http://127.0.0.1:4176/configurator/ . HTML не нужно открывать двойным щелчком: модулям Three.js нужен HTTP-сервер.

## Управление
- Перетаскивание левой кнопкой мыши — вращение.
- Колесо, кнопки + и − — масштаб.
- Один палец — вращение; два пальца — масштаб.
- Кнопки «Циферблат», «Профиль», «Задняя крышка» — фиксированные ракурсы.
- «Сбросить вид» — исходный ракурс и масштаб.
- «Автовращение» — включение и остановка вращения. Выбор ракурса останавливает автовращение.
- При фокусе на модели: стрелки — вращение, + и − — масштаб, Home — исходный вид.

## Что изменено
Использована и доработана исходная процедурная модель из проекта, а не создан новый скан часов. Исправлен проём в задней крышке и положение стекла над стрелками. Для конфигуратора убрана теневая плоскость, добавлены ракурсы, сенсорный масштаб и кнопки управления. Исправлена очистка обработчиков и цикла при уничтожении сцены.

Модель находится в src/assets/js/gl/watch.js, управление — в stage.js и pages/configurator.js. Это исполняемая геометрическая модель Three.js, отдельного файла GLB в поставке нет. Фотореалистичное совпадение с ранее сгенерированными изображениями не заявляется. Исходные изображения проекта сохранены.

## Проверка и размещение
Проверены сборка и синтаксис изменённых JS-модулей. Визуальная проверка WebGL в этой среде не выполнена: браузер отсутствует, загрузка браузера недоступна. Перед публикацией осмотрите три ракурса и проверьте управление на своём компьютере и телефоне.

В архиве есть обновлённая папка dist для размещения на существующем хостинге. Автоматическая публикация не выполнялась. У проекта также есть исходный scripts/check.mjs для проверки в локально установленном Chrome.
