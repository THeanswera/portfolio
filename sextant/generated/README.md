# Папка для сгенерированных изображений

Сюда кладутся картинки, сгенерированные по промптам из
`../ПРОМПТЫ-ДЛЯ-ГЕНЕРАЦИИ.md`. Имя файла — из списка в промптах
(`watch-greenwich.png`, `calibre-balance.jpg` и так далее).

Установка: из папки `sextant` выполнить

```bash
node scripts/install-images.mjs
```

Скрипт обрежет картинку по центру, приведёт к нужному размеру,
сохранит в `src/assets/img/` и уберёт прежние рендеры в резерв.

Посмотреть, что нашлось, ничего не меняя: `node scripts/install-images.mjs --dry-run`
Вернуть процедурные рендеры: `node scripts/install-images.mjs --restore`

Содержимое этой папки в репозиторий не попадает.
