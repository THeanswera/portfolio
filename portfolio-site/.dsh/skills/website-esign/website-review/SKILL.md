# Приёмка сайта

Сопоставь страницу с брифом и принятыми правилами дизайна.
Проверь первый экран, иерархию текста, изображения, переносы и переполнение на согласованных размерах экрана.
Проверь навигацию клавиатурой, фокус, подписи полей, ошибки форм и все основные переходы.
При доступном браузере запиши шаги воспроизведения каждой ошибки и сделай скриншот состояния. Статический анализ не называй проверкой взаимодействия.
Отдельно выяви вымышленные отзывы, демонстрационные данные и неработающие обещанные функции.
Выдай список: дефект; место; как воспроизвести; влияние; исправление.
В режиме проверки не меняй код. После отдельного задания на исправление работай только с подтверждёнными дефектами и перепроверь изменённые состояния.
