Политика конфиденциальности

Как сайт обращается с данными, которые вы вводите в формах заявки. Документ описывает состав данных, цели обработки, сроки хранения и права посетителя.

Содержание политики конфиденциальности

Коротко: что происходит с данными

Данные из формы заявки нужны только для ответа по вашему обращению. Они не передаются третьим лицам, не используются для рассылок и удаляются по запросу. Подробности — в разделах ниже.

1. Оператор и область действия

Оператор персональных данных — сервисный центр «ТехРемонт». Политика описывает, какие данные собирает форма заявки на сайте, зачем они нужны и как обрабатываются.

Политика распространяется на все страницы сайта: главную, страницы услуг, каталог, прайс-лист, страницу о компании и страницу контактов.

2. Какие данные собираются

Форма заявки запрашивает:

  • Имя — чтобы обратиться к вам при звонке
  • Телефон — для связи по заявке
  • Направление ремонта, тип и модель техники — чтобы подготовить запчасти и назвать стоимость
  • Описание неисправности — для предварительной оценки работ
  • Предпочтительный способ связи — звонок, Telegram или WhatsApp

Специальные категории данных (о здоровье, убеждениях, биометрия) не запрашиваются. Данные детей не собираются.

3. Зачем нужны данные

Данные используются исключительно для обработки обращения: связаться с вами, уточнить детали неисправности, согласовать время визита мастера, назвать стоимость ремонта и оформить гарантийные документы.

Мы не используем контакты для массовых рассылок и не передаём их третьим лицам для рекламы.

4. Согласие и его отзыв

Форма отправляется только после того, как вы отметите согласие на обработку персональных данных. Согласие даётся на срок, необходимый для обработки заявки и гарантийного обслуживания.

Отозвать согласие можно в любой момент: позвоните по телефону +7 (800) 555-35-35 или напишите на info@example.com. После отзыва данные удаляются, если нет законных оснований их хранить (например, действующей гарантии).

5. Файлы cookie и аналитика

Сайт не устанавливает файлы cookie и не подключает системы веб-аналитики, рекламные пиксели и сторонние счётчики. Шрифты загружаются с сервиса Google Fonts — при этом браузер обращается к внешнему домену.

В реальном проекте на этом месте должен быть перечень используемых счётчиков с возможностью отказаться от аналитических cookie.

6. Права пользователя

Вы вправе запросить сведения об обработке своих данных, потребовать их уточнения, блокирования или удаления, а также отозвать согласие. Запрос направляется на info@example.com или по телефону сервисного центра.

Ответ на обращение предоставляется в срок, установленный законодательством Российской Федерации о персональных данных.

7. Как защищаются данные

В реальном проекте передача данных из формы должна выполняться по защищённому протоколу HTTPS, доступ к заявкам — предоставляться только сотрудникам, работающим с обращениями, а сроки хранения — ограничиваться целями обработки.

Данные из формы передаются только оператору и хранятся не дольше, чем нужно для ответа по обращению.
